# Integritetspolicy för WorkoutCool

## 1. Inledning

På **WorkoutCool** tar vi din integritet på stort allvar.
I den här integritetspolicyn förklarar vi hur vi samlar in, använder och skyddar dina personuppgifter.
Genom att använda våra tjänster godkänner du den hantering som beskrivs nedan.

## 2. Uppgifter som vi samlar in

**Personuppgifter.** När du registrerar dig samlar vi in ditt namn, din e-postadress och andra uppgifter som rör din aktivitet på WorkoutCool.

**Användningsuppgifter.** Vi följer hur besökare använder sidorna på WorkoutCool, bland annat genom klick, sidvisningar och statistik över hur länkar används.

**Kakor.** Vi använder kakor för att förbättra din användarupplevelse och följa hur tjänsten används.

## 3. Så använder vi dina uppgifter

- **Tjänster.** Vi använder uppgifterna för att tillhandahålla, underhålla och förbättra våra tjänster.
- **Kommunikation.** Vi använder uppgifterna för att skicka dig uppdateringar, meddelanden eller marknadsföring (om du har samtyckt till det).
- **Analys.** Vi använder uppgifterna för att förstå hur våra tjänster används och löpande förbättra dem.

## 4. Delning av uppgifter med tredje part

Vi kan dela sammanställda eller anonymiserade uppgifter med betrodda samarbetspartner för marknadsföring, analys eller produktutveckling.
Vi säljer eller delar inga personuppgifter utan ditt uttryckliga samtycke.

## 5. Hur länge vi sparar dina uppgifter

Vi sparar dina uppgifter så länge ditt konto är aktivt eller så länge uppgifterna behövs för att tillhandahålla våra tjänster.
Vissa uppgifter kan arkiveras av rättsliga eller administrativa skäl eller av säkerhetsskäl.

## 6. Så skyddar vi dina uppgifter

Vi använder vedertagna säkerhetsåtgärder inom branschen för att hindra obehöriga från att komma åt, ändra eller radera dina uppgifter.

## 7. Dina rättigheter

Du har följande rättigheter.

- **Tillgång.** Du kan begära en kopia av dina personuppgifter.
- **Rättelse.** Du kan begära att felaktiga eller ofullständiga uppgifter rättas.
- **Radering.** Du kan begära att dina uppgifter raderas, såvida vi inte måste spara dem enligt lag.

## 8. Kakor

WorkoutCool använder kakor för att

- göra det lättare att navigera,
- följa upp webbplatsens prestanda,
- anpassa innehållet som visas.

Du kan stänga av kakor i webbläsarens inställningar.

## 9. Annonsering och regelefterlevnad

Vi följer annonseringsreglerna för plattformar som Facebook och Google.
Vi använder inte dina uppgifter på sätt som strider mot deras riktlinjer eller tillämpliga bestämmelser.
